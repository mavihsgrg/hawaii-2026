## ✅ Summary

| | |
|---|---|
| **Location** | Harbor side of Waikīkī, not on the sandy beach; a walk to the beach |
| **Overall rating** | Hotels.com 9.4/10 · Tripster 4.5/5 (5,249 ratings) · HotelPlanner reviews average 5.0 (small sample) |
| **Resort fee** | Mandatory; amount not confirmed. Wi-Fi is included |
| **Parking** | Secured valet about $62.83/night (Travelocity). Another source says self-park is extra |
| **Pool** | Infinity pool for guests 16+ |
| **Fit** | Good for pool time and harbor views; less convenient for the beach |

## 🛏️ Room types
| Room | View | Notes |
|---|---|---|
| Oceanfront Hokulea / Marina / Prime / Top / Vista | Ocean or harbor | Floor-to-ceiling windows |
| Lanai Suite | Varies | Only room type with a lanai |
| Ala Moana Suite (1 bedroom) | Varies | Larger |
| Prince Suite (2 bedrooms) | Ocean | Largest |

**Caveat:** most rooms have **no balcony**. Oyster calls this a major drawback. If you want outdoor space, book a Lanai Suite.

## 💵 Prices seen
- Tripster snapshot, August 2026: about **$247–359/night** for king or queen oceanfront rooms.
- One-bedroom king suite: about **$670/night**.
- Hotels.com snapshots (Jan–Mar 2026): about $213–216/night before fees.
