## Carry-on (survives lost luggage)
- [ ] IDs / Real ID, wallet, cards
- [ ] Medications (incl. lactase pills)
- [ ] Phone, chargers, power bank
- [ ] Swimsuits + one change of clothes
- [ ] Sunglasses

## Beach & water
- [ ] Reef-safe sunscreen (mineral; oxybenzone/octinoxate banned in HI)
- [ ] Rash guard / swim shirt
- [ ] Hats
- [ ] Sandals / water shoes
- [ ] Dry bag for boat tours
- [ ] Motion-sickness meds (Molokini boat / Hāna road)

## Haleakalā (it's ~35–45°F and windy at the summit at sunset)
- [ ] Warm layer / fleece each
- [ ] Wind-/rain-resistant jacket each
- [ ] Long pants, closed shoes
- [ ] Beanie / gloves (optional)

## Day trips
- [ ] Small daypack
- [ ] Refillable water bottles
- [ ] Sturdy walking shoes
- [ ] Light rain jacket (Hāna / Upcountry rain)
- [ ] Snacks for Hāna / summit

## 🎂 Birthday dinner
- [ ] One nicer outfit each

## Tech
- [ ] Offline maps downloaded
- [ ] Waterproof phone pouch
